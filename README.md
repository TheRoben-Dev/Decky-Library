# Decky-Library

Decky Loader plugins and CSS Loader themes for Bazzite / SteamOS handhelds. Each one lives in its own folder.

## Themes (CSS Loader)
| Theme | What it does |
|---|---|
| [nightgrid-theme](nightgrid-theme/) | Retro-terminal Game Mode theme based on the Nightgrid app: near-black grid canvas, cyan data accents, magenta outlined selection, uppercase mono labels. Palette, custom colors, grid, font, glow and scanline options. |

Install a theme by extracting its zip into `~/homebrew/themes/`, then refresh CSS Loader and enable it.
